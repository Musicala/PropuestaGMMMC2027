# Ilustraciones de instrumentos

Colección de 16 ilustraciones SVG originales creadas para esta propuesta: guitarra, piano, violín, violonchelo, canto/coro, flauta traversa, clarinete, saxofón, oboe, fagot, trompeta, trombón, corno francés, tuba, percusión y ensamble. No se copiaron imágenes de terceros. Estilo y colores compartidos; fuentes editables en esta carpeta.

El mapa de la orquesta es un esquema orientativo, no una planta técnica ni una promesa de dotación o distribución fija. Los referentes de ciudad se atribuyen y enlazan directamente en la sección de proyección de la web.
